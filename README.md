A two-sentence horror story for make.fun's Two-Sentence Horror bounty. All week the night watchman counted the museum's forty-one wax figures and found only forty; tonight he found forty-one, and now he stands among them in the dark, holding his breath, hoping it cannot count. The program writes the story, exactly two sentences, to /output/entry.txt.

## Run it

```sh
python3 main.py
```
